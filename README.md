# image-cv

Учебный проект по базовой обработке изображений и расчёту метрик качества на Python.

## Суть

Программа загружает изображение, добавляет гауссов шум, сглаживает его фильтром Гаусса, выделяет контуры оператором Собеля и выполняет адаптивную бинаризацию. Качество фильтрации оценивается через метрики `MSE` и `PSNR`.

**Использовано:**
- Обработка массивов и фильтры: `Python`, `NumPy`, `SciPy`
- Работа с изображениями: `Pillow`
- Автотесты: `pytest`

## Что проверяют тесты
- Перевод RGB в оттенки серого и размерность массива
- Корректность расчёта `MSE` и `PSNR`
- Улучшение `PSNR` (и снижение `MSE`) после фильтрации шума на разных уровнях зашумления (`@pytest.mark.parametrize`)
- Обработка некорректных параметров (`sigma < 0`, чётный размер окна)

## Как запустить
1. Установить зависимости:
```powershell
pip install -r requirements.txt
```
2. Запустить программу и автотесты:
```powershell
python main.py
pytest -v
```
